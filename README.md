# 🛵 Né Kẹt Xe Sài Gòn

Một mini-game mình lấy cảm hứng từ Flappy Bird huyền thoại, bạn sẽ điều khiển chiếc xe máy len lỏi qua các "chốt kẹt xe" đậm chất đường phố.

**🎮 Trải nghiệm tại đây:** https://quangvinh-2011.github.io/flappy-sai-gon/

## Cách chơi

- Nhấn chuột, chạm màn hình, hoặc bấm phím `Space` để xe bốc đầu lên
- Né các rào chắn công trình đang lấn ra đường
- Mỗi lần vượt qua một chốt được +1 điểm
- Kỷ lục của bạn sẽ được tự động lưu lại tha hồ phá đảo

## Công nghệ sử dụng

- HTML5 Canvas API cho toàn bộ đồ họa game
- Vanilla JavaScript (không dùng thư viện/framework ngoài)
- Web Audio-style particle effect cho hiệu ứng khói khi bốc đầu xe
- `localStorage` để lưu điểm cao nhất giữa các lần chơi

## Cách chạy local

Chỉ cần tải file `index.html` về và mở trực tiếp bằng trình duyệt, không cần cài đặt gì thêm.
